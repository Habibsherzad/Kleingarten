# Kleingarten Blog

Kleiner Flask-Blog für einen Kleingartenverein.

Mitglieder können sich registrieren, Beiträge schreiben, Bilder hochladen und Nachrichten austauschen.

## Starten

```
pip install flask python-dotenv werkzeug
python app.py
```

Danach im Browser: http://127.0.0.1:5000

## Hinweise

- Nutzerdaten liegen unter `data/`
- Uploads unter `static/uploads/`
- Admin-Login: siehe `data/users.json`
